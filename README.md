# Portfolio | Muhammad Usman Safdar

MERN stack developer portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Project structure

```
portfolio-new/
├── public/          # Static assets (CV, logos, project images)
├── src/
│   ├── assets/      # Images and media
│   ├── components/  # Reusable UI (Navbar, ProjectCard, etc.)
│   ├── data/        # portfolioData.js
│   ├── pages/       # Home, Projects, Skills, Contact
│   ├── App.jsx
│   ├── main.jsx
│   └── index.css
├── index.html
├── package.json
├── vite.config.js
├── netlify.toml
└── vercel.json
```

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
